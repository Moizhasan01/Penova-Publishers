# Beacon Publisher Launch

Beacon Publisher — Lovable Build Prompt

PROJECT BRIEF

Build a premium, ultra-professional multi-page marketing website for Beacon Publisher, a publishing services company offering Publishing, Ghostwriting, Editing, Marketing, Children's Books, and Illustration services. The site must look like a high-end, established publishing house — polished UI/UX, premium typography, generous white space, smooth micro-interactions, and zero "template" feel. Reference-quality benchmarks: parkerpublishers.com and alpacaauthors.com (match their structure, page count, and sales-page rhythm — hero → trust logos → services → genres/portfolio → process steps → testimonials/reviews → FAQ → footer), but with fully original layout, copy, and a distinctly more refined visual identity than those references.

BRAND IDENTITY

Name: Beacon Publisher

Tagline: "The Light of Knowledge, Rising From the Page"

Logo concept: A lighthouse (tower + lantern + warm glow + sunburst medallion ring) rising directly out of an open book, whose spine forms the lighthouse's base/plinth (this is Concept A from the brand deck — use this as the primary logo treatment; a stacked-book-pedestal variant exists as a secondary option).

Color palette (derive full UI palette from this):

Deep Navy (primary/dark backgrounds, headers) — e.g. #0F1B2D / #14243B

Warm Gold / Amber (lantern glow, accents, CTA highlights, spine trims) — e.g. #C9A24B / #E8B84B

Cream / Warm White (body backgrounds, cards) — e.g. #FAF6EE

Supporting Brown (book covers/spines, secondary accent) — e.g. #6B4A2F

Typography: A refined serif (editorial, book-like) for headlines paired with a clean modern sans-serif for body text and UI — evokes "publishing house," not "startup SaaS."

Visual motifs to reuse across the site: lighthouse silhouette, open book pages, subtle sunburst/ray patterns, gold foil-style dividers, book-spine color blocks, soft lantern-glow gradients behind hero sections.

SITE STRUCTURE — 10 PAGES + 1 LANDING PAGE

Build every page below as a real route with fully written, on-brand copy and appropriate imagery/placeholders (no lorem ipsum):

Home — Hero with logo/tagline + CTA ("Get a Free Quote" / "Start Your Book"), "Who We Are" intro strip, services overview grid (6 services as cards linking to their pages), "Genres We Cover" icon grid, featured/recent work showcase, process/how-it-works steps, trust strip (platforms we publish on: Amazon KDP, Barnes & Noble, Apple Books, Kobo, IngramSpark, Google Books, etc.), testimonials/reviews carousel, FAQ accordion, final CTA banner.

About — Brand story, mission, founder/team narrative, values, why authors choose Beacon Publisher.

Publishing — Self-publishing & full-service publishing packages, distribution channels, ISBN/formatting/print+ebook details, process timeline, CTA.

Ghostwriting — Packages/tiers, genres covered, process (interview → outline → drafts → revisions), sample-style showcase, CTA.

Marketing — Author/book marketing services (social campaigns, ads, PR, launch strategy), package tiers, CTA.

Editing — Editing tiers (developmental, copy editing, proofreading), before/after style comparison section, CTA.

Children's Books — Dedicated section for children's publishing, illustration+story pairing, sample spreads gallery, CTA.

Illustration — Illustration styles/services, portfolio gallery, process, CTA.

Contact — Contact form (name, email, phone, message, project type dropdown), map/location placeholder, socials, response-time promise, FAQ mini-section.

Privacy Policy — Standard legal/privacy page (clean typographic layout, no design elements needed beyond consistent header/footer).

Landing Page (standalone, no main-nav header) — Focused campaign/offer page: single strong hero, benefit bullets, social proof, one clear CTA form, minimal navigation — built for ad traffic conversion.

GLOBAL COMPONENTS (build once, reuse everywhere)

Header/Nav: Logo left, services dropdown (Publishing, Ghostwriting, Editing, Marketing, Children's Books, Illustration), About, Contact, sticky on scroll, prominent "Get Quote" button, mobile hamburger menu with slide-in drawer.

Footer: 4-column layout — Services links, Company links (About, Blog placeholder, Terms, Privacy), Contact details (phone, email, address placeholder), Social icons (Facebook, Instagram, TikTok, Pinterest, LinkedIn) + newsletter signup + copyright line.

"We Publish On" logo strip — horizontal scrolling/marquee row of major distribution platform names.

Trust/Review badges section — visual placeholders for Trustpilot, Google Reviews, Reviews.io style rating widgets (static/placeholder is fine).

Reusable CTA banner component — gold-on-navy, used at bottom of every service page.

Testimonial cards — client quote, name, book title, star rating.

Process/Steps component — numbered horizontal (desktop) / vertical (mobile) timeline used across Publishing, Ghostwriting, Editing pages.

UI/UX REQUIREMENTS

Fully responsive: flawless on mobile, tablet, desktop.

Smooth scroll-reveal animations on section entry (subtle, not gimmicky).

Hover states on all cards/buttons with gentle elevation/glow (gold accent).

Consistent 8pt spacing system, clear visual hierarchy, generous line-height for readability.

Fast-loading, accessible (proper contrast, alt text, semantic HTML, keyboard navigation).

Every page shares the same header/footer and color system — no visual drift between pages.

Use high-quality stock-style imagery placeholders themed around books, writing, libraries, lighthouses, and coastal/editorial moods matching the navy-gold-cream palette.

TONE OF COPY

Confident, warm, editorial, and trustworthy — written for aspiring and established authors. Avoid generic corporate filler; write like a boutique publishing house that genuinely cares about each author's story.

DELIVERABLE EXPECTATION

A cohesive, production-ready, multi-page website (11 pages total as listed) with consistent branding, working internal navigation between all pages, and a polished, premium feel suitable for client presentation — matching or exceeding the professionalism of parkerpublishers.com and alpacaauthors.com.
